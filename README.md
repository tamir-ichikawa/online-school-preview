# オンラインスクール デザイン確認サイト

ページの見た目・内容・導線を確認するための静的な張りぼてです。

- 入口：デザイン案を選ぶ画面。
- 第4案・PLAY：play-v2/index.html。画面いっぱいの街と31人の異なる活動を描く、イラスト調の3Dアニメーション。ちらつき・膝・接地を調整した版です。初稿 play-v1/ は保存しています。
- 第3案・スタジオ型：studio-v2/index.html。公開・受講・本部・代理店・講師の静的画面。内容のポップアップは使わず、詳細ページや画面内の確認欄へ進みます。初稿 studio-v1/ も保存しています。
- スクール型：school-v2/index.html。創設者の漫画、受講画面、本部・代理店・講師の管理画面を含みます。
- 保存したスカイブルー案：sky-v2/index.html。

人物・教材・記録・数値・課題基準は架空または仮の表示例を含みます。正式名称・商品条件等は確認待ちです。漫画は提供原文と、以前の仮採用イラストを再利用しています。

認証・API・DB・実登録・保存・送信・承認・決済の機能はありません。

## デザイン案を追加する

1. 新しい案を別フォルダに置き、以前の案を残します。
2. designs.mjsに名前・画像・導線を追加します。
3. 表示と操作を確認してからmainへ反映します。GitHub Pagesはmainブランチのルートを公開します。

assets/は自作のサンプル動画・字幕・ポスター、images/は画面プレビューです。設計資料・原本のバックアップ・検証資料は収録していません。ローカル原本との自動同期はありません。

### 編集する場所

- HTML：文章・導線・ページ構成。`style.css`と`city.css`：外観・レスポンシブ。
- `play-v2/paper-models.mjs`：薄い立体形状、人物の関節、家具、小物、描画のまとめ方。
- `play-v2/people-motion.mjs`：各人の動作、歩行・接地・方向転換。
- `play-v2/city.mjs`：31人の配置、カメラ、描画、停止・場面切替。
- `play-v2/site.mjs`：メニュー・シーン読込・静止画への代替表示。`island.mjs`は以前の島。
- `play-v2/assets/city-poster.png`：街の読込前・WebGLが使えない場合の静止画。
- `designs.mjs`：公開トップの案一覧。`gallery.mjs`・`gallery.css`：一覧表示。
- `shared/`：既存3案の共通受講UI。変更は3案すべてに影響します。

Three.js 0.180.0を`vendor/`に同梱しています。MITライセンスの`THREE-LICENSE.txt`を保持してください。CDNやビルド、npmインストールは不要です。KOKUYOの参考サイトの画像・モデル・コードを取り込んだものではありません。

### 維持する品質

説明は短く、必要な詳細はページ内の適切な場所や別ページへ。開発・確認用の文言を画面へ追加しない。内容をポップアップへ詰め込まない。ボックス内は四辺に余白を確保し、文字を端に密着させない。下層ページもトップと同じ品質で仕上げる。受講画面は教材・課題・質問を中心とし、メモ等の不要機能を戻さない。

PLAYの修正時は、膝の曲がり、足首の水平、接地、反転形状、面の奥行きの重なり、ループのつなぎを再確認してください。全員同じ反復動作へ戻さず、停止時にカメラが揺れない状態を維持します。OSの動きを減らす設定とWebGL代替表示のコードはありますが、全端末での動作を保証するものではありません。

### 確認と公開

リポジトリのルートをHTTPサーバーで配信してください。`file://`ではES Modulesが動きません。例：Pythonがある環境で`python -m http.server 4176 --bind 127.0.0.1`。`.mjs`をJavaScriptのMIMEで配信するサーバーを使います。

390 / 768 / 1440 / 1920px程度で、トップ・下層・メニュー・場面切替・停止/再生・一覧へ戻るリンクを確認。GitHub Pagesの`/online-school-preview/`配下で動くよう相対パスを使います。ユーザーが公開を依頼した変更だけをコミットし、`main`へのpush後にPagesの完了と外部URLを確認してください。秘密情報、個人情報、内部資料、姿勢確認用の`_qa`画面を追加しないでください。

詳しい業務設計、制作経緯、ローカル検証スクリプトはこの公開リポジトリにはありません。プロジェクト全体を引き継ぐ場合は、依頼者が持つ作業フォルダの`AI_HANDOFF.md`と`AGENTS.md`を先に確認してください。GitHubの画面から正式料金・権限・サービス条件を推定しないでください。
