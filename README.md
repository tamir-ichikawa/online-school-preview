# オンラインスクール デザイン確認サイト

ページの見た目・内容・導線を確認するための静的な張りぼてです。

- 入口：デザイン案を選ぶ画面。
- 第3案・スタジオ型：studio-v1/index.html。構成と構図を比較する1ページの案。受講画面・管理画面はこの案では制作していません。
- スクール型：school-v2/index.html。創設者の漫画、受講画面、本部・代理店・講師の管理画面を含みます。
- 保存したスカイブルー案：sky-v2/index.html。

人物・教材・記録・数値・課題基準は架空または仮の表示例を含みます。正式名称・商品条件等は確認待ちです。漫画は提供原文と、以前の仮採用イラストを再利用しています。

認証・API・DB・実登録・保存・送信・承認・決済の機能はありません。

## デザイン案を追加する

1. 新しい案を別フォルダに置き、以前の案を残します。
2. designs.mjsに名前・画像・導線を追加します。
3. 表示と操作を確認してからmainへ反映します。GitHub Pagesはmainブランチのルートを公開します。

assets/は自作のサンプル動画・字幕・ポスター、images/は画面プレビューです。設計資料・原本のバックアップ・検証資料は収録していません。ローカル原本との自動同期はありません。
