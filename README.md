# オンラインスクール デザイン確認サイト

GitHub Pagesで、ページの見た目・配置・内容・導線を確認するための静的な張りぼてです。

- 最初のページ：デザイン案を選ぶ入口。
- 現行案：スカイブルー。公開サイト・受講画面・本部・代理店・講師の管理画面。
- 人物・記録・件数・評価基準には架空の表示例を含みます。
- 実際の申込・登録・保存・送信・決済・権限管理は行いません。正式なスクール名・商品条件等は確認待ちを含みます。

## デザイン案を追加する

1. 新しい案を別フォルダに配置します。前の案は残します。
2. `designs.mjs`に案の名前・画像・リンクを追加します。
3. ブラウザーで確認してから`main`へ反映します。GitHub Pagesは`main`ブランチのルートを公開します。

## 構成

- `index.html` / `gallery.css` / `gallery.mjs` / `designs.mjs`：デザイン選択画面。
- `sky-v2/`：現行のスカイブルー版。
- `assets/`：自作のサンプル動画・字幕・ポスター。
- `images/`：デザイン案の画面プレビュー。
- `.nojekyll`：静的ファイルとして公開する設定。
